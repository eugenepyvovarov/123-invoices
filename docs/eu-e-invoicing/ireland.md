# Ireland

ISO: `IE` · Research date: 2026-07-24.

## Mandatory status (as of 2026-08-11)

| Obligation | Mandatory now? |
| --- | --- |
| B2G receive | **Yes** (2014/55) |
| B2G / B2B issue | **No** |

**How to integrate:** none. [shared/peppol-en16931.md](shared/peppol-en16931.md) only if a public body requires EN.

## Snapshot

Public bodies must **accept** EN 16931 invoices. There is **no B2G or B2B issue mandate**. Revenue has not launched a KSeF/SdI equivalent.
