# Czechia

ISO: `CZ` · Research date: 2026-07-24.

## Mandatory status (as of 2026-08-11)

| Obligation | Mandatory now? |
| --- | --- |
| B2G receive | **Yes** (2014/55) |
| B2B / B2G issue | **No** |
| Tax-authority invoice API | **No** |

**How to integrate:** none for general B2B. [shared/peppol-en16931.md](shared/peppol-en16931.md) only on request.

## Snapshot

Public bodies must **accept** e-invoices. There is **no general B2B or B2G issue mandate**. No nationwide CTC comparable to NAV or KSeF.
